### 🚀 Projetos em Destaque

**🔹 Metadado Spark — Motor de Ingestão Orientado a Metadados**

Projeto desenvolvido durante meu estágio em Engenharia de Dados na Xerlock.

- Desenvolvimento de pipelines de ingestão utilizando Apache Spark e PySpark.
- Ingestão de arquivos CSV e bancos SQL via JDBC.
- Gerenciamento de metadados utilizando MongoDB.
- Armazenamento em Data Lakehouse com MinIO, Apache Hive e Apache Iceberg.
- Implementação de estratégias de carga completa, incremental por bloco e MERGE por chave.
- Consultas analíticas com Trino e integração de serviços usando Docker.

**🔹 Data Mart de Vendas — ETL com Python e PostgreSQL**

- Construção de um processo ETL utilizando Python, Pandas e PostgreSQL.
- Tratamento, transformação e validação de dados de vendas.
- Modelagem dimensional com tabelas fato e dimensão.
- Implementação de controle de histórico utilizando SCD Tipo 2.
